# Zadání: kapitola 3.2

Doslovné zadání uživatele z 29. 10. 2026. Mezi kapitolami 3.1 a 3.2 vznikla kapitola 2.8 (úroveň obtížnosti). Po jejím ručním testu uživatel napsal:

> můžeš pokračovat kapitolou 3.2.

Obsah kapitoly určil schválený plán fáze 3 (viz [zadání kapitoly 3.1](01-e2e-testy.md)): okraje kolem výřezů telefonů, tlačítko pro celou obrazovku, menu na malých i velkých displejích a kontrolní snímky pro několik velikostí.
